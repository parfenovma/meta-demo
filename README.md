# MetaNDT Pluto demo

Интерактивный Pluto-ноутбук по ультразвуковому NDT с метаструктурами, который
можно запустить без опыта программирования. Численное ядро находится в
отдельной библиотеке [`parfenovma/meta-ndt`](https://github.com/parfenovma/meta-ndt).

Первый пример отвечает на один узкий вопрос: **какой выигрыш дефектного эха
должен дать наш STG-кирпичик, чтобы matched filter начал устойчиво видеть
дефект при заданном шуме?** Это what-if стенд, а не готовый результат FEM.

> Если вы хотите просто открыть демонстрацию, начните с
> **[START_HERE.md](START_HERE.md)**. Там отдельные инструкции для Windows,
> macOS и Linux.

## Что получится на экране

- ползунок уровня шума;
- ползунок гипотетического выигрыша эха `g`;
- образец с дефектом или без него;
- новые воспроизводимые реализации шума;
- наглядное сравнение обнаружений в серии из 100 опытов;
- точная схема STG-«кирпичика» со сдвигом профилей вырезов на полпериода;
- схема кирпичика, условного дефекта, 31 приёмника и места добавления шума;
- разложение учебного профиля на эхо, шум и их сумму;
- обработанный matched-filter профиль и общий порог решения при `Pfa = 5%`;
- явная граница между настоящей геометрией и ещё не рассчитанным эхом.

При `g = 1` STG-сценарий совпадает с прямой полосой. Затем можно поднимать `g`
и искать минимальный выигрыш, который пересекает порог при выбранном шуме.
Так демо формулирует требование к будущему расчёту, не выдавая гипотезу за факт.

## Быстрый запуск из терминала

Нужна официальная Julia `1.10` или новее.

```bash
julia --startup-file=no --project=. start.jl
```

Первый запуск устанавливает Pluto и PlutoUI в отдельное окружение `demo/`.
Затем откроется `notebooks/virtual_defectoscope.jl`.

## Библиотека действительно отдельно от Pluto

Ноутбук создаёт простой учебный шаблон, а шум и детектор вызывает через
публичный API `MetaNDT`:

```julia
using MetaNDT
using LinearAlgebra

gain = 1.5                    # гипотеза, не результат расчёта
y = collect(-30.0:2.0:30.0)
shape = @. exp(-0.5 * (y / 8.0)^2)
straight = 15 .* shape ./ norm(shape)
stg = gain .* straight
measurement = simulate_paired_measurement(
    stg,
    straight;
    noise_model=GaussianReceiverNoise(9),
    signal_present=true,
    measurement_index=3,
)
decisions = detect_pair(
    stg,
    straight,
    measurement,
)

decisions.primary.found  # true
decisions.control.found  # false
```

`matched_filter` принимает обычные вещественные или комплексные Julia-массивы.
Когда появятся парные STG-отклики «дефект / без дефекта», они заменят два
учебных массива без переделки детектора или интерфейса. Граница слоёв и план
научного стенда описаны в
[`meta-ndt/ARCHITECTURE.md`](https://github.com/parfenovma/meta-ndt/blob/main/ARCHITECTURE.md).

## Что настоящее, а что демонстрационное

Настоящее сейчас:

- геометрия STG-ячейки `L = 17 mm`, `H = 7 mm`, `A = 2.5 mm`, `N = 2`;
- сдвиг профилей вырезов на `T/2` и общая толщина `H - A = 4.5 mm`;
- общий matched-filter детектор из библиотеки `MetaNDT`.

Демонстрационное:

- гладкий 31-точечный шаблон дефектного эха;
- множитель эха `g`, который задаёт пользователь;
- независимый гауссовский приёмный шум;
- детектор, который заранее знает правильный шаблон;
- аналитическая вероятность для этой идеализированной модели.

Следующий научный шаг — заменить учебный шаблон парой STG FEM-сцен с дефектом
и без него, сохранив тот же интерфейс и одинаковую модель шума.
