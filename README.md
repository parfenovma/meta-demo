# MetaNDT: виртуальный стенд для опытов с волнами

Шесть готовых опытов в Pluto: динамическая масса, объёмный модуль,
преломление, поглощение, акустическая маскировка и плоская STG-линза.
Вы выбираете образец, запускаете импульс, ставите датчик мышью
и сравниваете результат с контролем. Программировать для этого не нужно.

**Методичка:** [главы Markdown](docs/practicum/README.md),
[единый PDF](output/pdf/metamaterials-practicum.pdf),
[HTML для браузера](output/pdf/metamaterials-practicum.html).
В ней пошаговые работы, формулы с обозначениями, задания, протокол
и библиографические ссылки на статьи и книгу *Acoustic Metamaterials*.

> Для запуска нужны **оба репозитория: meta-demo и meta-ndt**.
> Скачивайте или клонируйте их вместе и кладите в соседние папки.
> Одна `meta-demo` не содержит вычислительную библиотеку.
> PDF и HTML методички можно читать отдельно, без установки стенда.

## Что понадобится

- Компьютер с macOS или Windows и современный браузер.
- Интернет для первой загрузки Julia, репозиториев и пакетов.
- Две соседние папки: `meta-demo` и `meta-ndt`.
- Желательно 8 ГБ RAM и несколько ГБ свободного места с запасом.
  Это ориентир, не измеренный минимальный системный предел.

COMSOL, MATLAB, Python, платные ключи и отдельное Gmsh-приложение
для прохождения работ не нужны. Julia сама установит зависимости,
включая Pluto. Общая среда содержит и расчётные пакеты, хотя основная
коллекция при просмотре не запускает FEM.

## 1. Установите Julia

Для этой версии используем проверенную ветку **Julia 1.10**.
Команды явно выбирают её, не меняя вашу глобальную версию по умолчанию.
В `demo/Manifest.toml` зафиксировано окружение Julia 1.10.12.
Если команда `julia --version` показывает другую версию, не обязательно
менять её: запись `+1.10` выбирает нужную ветку только для этого запуска.

### macOS: Apple Silicon и Intel

1. Откройте **Terminal**: `Command+Пробел`, затем `Terminal` и Enter.
2. Откройте [официальную инструкцию Juliaup](https://github.com/JuliaLang/juliaup#installation).
   Эта команда скачивает и запускает официальный установщик:

   ```sh
   curl -fsSL https://install.julialang.org | sh
   ```

3. Подтвердите подходящие вам настройки установки.
4. Закройте Terminal и откройте заново, чтобы обновился путь к Julia.
5. Добавьте нужную ветку и проверьте её:

   ```sh
   juliaup add 1.10
   julia +1.10 --version
   ```

Должна появиться строка `julia version 1.10...`. Если Julia уже установлена
без Juliaup, не удаляйте её наугад: можно пользоваться имеющейся 1.10
без `+1.10` или согласовать установку Juliaup с руководителем.

### Windows

1. На [официальной странице Julia](https://julialang.org/downloads/)
   выберите установку через Microsoft Store. Не скачивайте установщик
   с посторонних сайтов.
2. Альтернатива той же Store-установки: откройте PowerShell или Windows
   Terminal и выполните:

   ```powershell
   winget install --name Julia --id 9NJNWW8PVKMN -e -s msstore
   ```

3. Закройте окно терминала и откройте новое.
4. Добавьте ветку и проверьте её:

   ```powershell
   juliaup add 1.10
   julia +1.10 --version
   ```

Если Store заблокирован школой или организацией, попросите помочь
с официальным способом установки. Не отключайте защиту системы ради проекта.

### Linux

Официальная Unix-команда Juliaup та же, что для macOS. После нового
открытия терминала добавьте `1.10`. Дальнейшие команды запуска одинаковы;
это не означает, что все дистрибутивы проверены.

## 2. Скачайте или клонируйте оба репозитория

Выберите один способ: два ZIP-архива или две команды Git.
В обоих случаях результат один — соседние папки `meta-demo` и `meta-ndt`.

### Без Git: два ZIP-архива

Откройте [meta-demo](https://github.com/parfenovma/meta-demo) и
[meta-ndt](https://github.com/parfenovma/meta-ndt). На каждой странице
нажмите **Code → Download ZIP**. Распакуйте архивы. Переименуйте
`meta-demo-main` в `meta-demo`, `meta-ndt-main` в `meta-ndt`
и положите рядом в одну папку, например `acoustic-lab`:

```text
acoustic-lab/
  meta-demo/
    start.jl
    demo/
    notebooks/
    data/canonical/
  meta-ndt/
    Project.toml
    src/
```

`start.jl` должен лежать непосредственно внутри `meta-demo`, а не
ещё на уровень глубже. Не запускайте файлы внутри ZIP.

### Через Git: клонируйте пару за один подход

Откройте терминал в папке, где хотите держать проект. Эти команды
одинаковы для macOS Terminal и Windows PowerShell с установленным Git:

```sh
mkdir acoustic-lab
cd acoustic-lab
git clone https://github.com/parfenovma/meta-ndt.git
git clone https://github.com/parfenovma/meta-demo.git
cd meta-demo
julia +1.10 --startup-file=no --project=. start.jl
```

**Выполните обе команды `git clone` до запуска Julia.** Они создают
соседние папки внутри `acoustic-lab`. Не клонируйте библиотеку изнутри
`meta-demo`: тогда она окажется не там, где её ищет приложение.
Если Julia ещё не установлена, сначала закончите шаг 1.

При обновлении сначала закройте стенд, затем обновите **обе** папки.
Из общей папки `acoustic-lab`:

```sh
git -C meta-ndt pull --ff-only
git -C meta-demo pull --ff-only
```

При установке через ZIP заново скачайте оба архива. Если вы меняли
исходники, сохраните свои изменения перед заменой папок.
Стенд проверяет согласованность моделей и готовых данных; не отключайте
проверку, если обновилась только одна половина проекта.

## 3. Запустите приложение

### macOS

1. Откройте Terminal.
2. Введите `cd ` с пробелом после букв.
3. Перетащите папку **meta-demo** из Finder в окно Terminal.
4. Нажмите Enter: терминал перейдёт в нужную папку.
5. Выполните:

   ```sh
   julia +1.10 --startup-file=no --project=. start.jl
   ```

### Windows

1. В Проводнике откройте распакованную папку **meta-demo**.
2. Нажмите адресную строку сверху, введите `powershell` и нажмите Enter.
   Откроется терминал в этой папке. Права администратора не нужны.
3. Выполните:

   ```powershell
   julia +1.10 --startup-file=no --project=. start.jl
   ```

Если PowerShell открыт другим способом, сначала перейдите через `cd`
и путь в кавычках. Команда `dir` должна показывать `start.jl`.

### Что произойдёт дальше

Первый запуск подключит соседнюю библиотеку и скачает пакеты в окружение
проекта. Не закрывайте терминал только потому, что некоторое время
нет новых строк: первая компиляция может быть долгой.

Затем откроется браузер с **«Метаматериалы: шесть опытов»**. Если браузер
не открылся, скопируйте адрес из терминала: `http://localhost:...`
или `http://127.0.0.1:...`. Номер порта может отличаться; не набирайте
адрес из чужого скриншота.

Терминал оставьте открытым. При следующем запуске используйте ту же
команду; устанавливать Julia и скачивать архивы заново не нужно.

## 4. Первый опыт

1. Выберите **«01 · Отрицательная масса»**.
2. Оставьте **192 Hz** и **«Мембрана с грузом»**.
3. Нажмите **«Запустить импульс»**. Слева контроль, справа выбранный образец.
4. Прочитайте шкалу: здесь показано давление в паскалях.
5. Нажмите на цветной канал справа от мембраны. Появятся датчик,
   его координаты и две записи.
6. Дальше следуйте [работе 1](docs/practicum/chapters/03-mass.md).

У основной коллекции нет построения сетки по кнопке. Поля уже входят
в `data/canonical/`. После загрузки карточки перенос датчика не обращается
к решателю. Крупный набор STG может открываться дольше остальных.

Скрипты `start_windows.bat`, `start_macos.command`, `start_linux.sh`
используют Julia **по умолчанию**. Для воспроизводимого первого запуска
выше дана явная команда `+1.10`.

## 5. Как закончить

Сохраните протокол и скриншоты. Закройте вкладку, вернитесь в терминал
и нажмите `Ctrl+C`. Если появилось приглашение Julia, введите `exit()`.
Готовые поля останутся на диске. Основная коллекция не сохраняет
автоматически ваш отчёт и не обещает восстановить положение всех
элементов между перезапусками.

## Если запуск не удался

| Что видно | Что проверить |
|---|---|
| `julia` или `juliaup` не найдены | Откройте новый терминал после установки. Проверьте официальный установщик и PATH. |
| Не найден `1.10` | Выполните `juliaup add 1.10`. |
| Не найден `start.jl` | Терминал должен находиться внутри распакованной `meta-demo`. |
| Требуется соседняя библиотека | Скачаны оба репозитория; `meta-ndt` лежит рядом с `meta-demo`, не внутри неё. |
| Ошибка загрузки пакета | Проверьте сеть и повторите запуск. Не удаляйте Manifest наугад. |
| Не совпадает хеш готовых данных | Проверьте согласованность версий двух папок и данных. Не отключайте проверку. |
| Ошибка `DecompressionStream` | Используйте современный браузер и прочитайте сообщение под карточкой. |
| Видна кнопка «Рассчитать опыт» | Уберите дополнительные флаги: обычный старт открывает готовую коллекцию. |

Для помощи скопируйте первую строку ошибки, несколько следующих строк,
версию Julia, систему и команду запуска. Не присылайте пароли и содержимое
посторонних окон. Для локальной работы не нужно открывать Pluto в публичную
сеть или отключать защиту системы.

## Исследовательские режимы: не первый шаг практикума

Дополнительный флаг добавляют **после** `start.jl`:

| Флаг | Что открывается |
|---|---|
| `--workbench` | Редактор исследований: трубка и STG, новые расчёты и сравнение запусков |
| `--solid` | Расширенная плоская STG-линза |
| `--cloak` | Расширенная покрытая трубка |
| `--water` | Галерея акустико-упругих образцов в воде |
| `--single`, `--array` | Одиночный цилиндр или редактор массива |
| `--stg` | Старый what-if дефектоскоп с синтетическим эхом и заданным усилением |

Здесь могут запускаться сетки и тяжёлые расчёты. Ручной ввод, CSV
и полка запусков этих режимов не являются функциями основной коллекции.
Заданный множитель эха старого дефектоскопа не доказывает выигрыш STG.

## Устройство проекта и проверки

Физика отделена от Pluto в [meta-ndt](https://github.com/parfenovma/meta-ndt).
Пояснения карточек — `src/assets/canonical_lessons.json`, интерфейс —
`src/CanonicalUI.jl` и `src/assets/canonical.*`. Главы и инструкция
сборки документации — [docs/practicum](docs/practicum/README.md).

Проверки из корня `meta-demo`:

```sh
julia +1.10 --startup-file=no --project=demo test/canonical_ui.jl
julia +1.10 --startup-file=no --project=demo test/canonical_pluto.jl
node test/canonical_viewer.cjs
python3 tools/build_practicum.py --check
```

Node.js и Python здесь нужны разработчику, не ученику для запуска стенда.
Физические проверки: [CANONICAL_VALIDATION.md](docs/CANONICAL_VALIDATION.md).
Расширенные режимы: [WORKBENCH_UI.md](docs/WORKBENCH_UI.md),
[STG_TRANSIENT.md](docs/STG_TRANSIENT.md),
[WATER_TRANSIENT.md](docs/WATER_TRANSIENT.md),
[POINT_SENSOR.md](docs/POINT_SENSOR.md).

Локально проверена macOS; Windows-команды сверены с официальной
документацией Juliaup, но чистая Windows-установка в этой сессии
не выполнялась.
