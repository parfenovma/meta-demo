# Переход к пяти опытам

Архив изменения от 16 октября 2026 года.

В основной коллекции остались `mass`, `bulk`, `absorber`, `cloak`, `focus`.
Опыт с преломлением удалён из кода, данных, меню, ноутбука, рисунков,
заданий и библиографии. Полное название книги сохранено.

## Что произошло с данными

Реализации оставшихся решателей сопоставлены с библиотекой
`aa9993d6e083ff820f6eefb7792c4258bf428434`:
cloak совпал побайтово; мембрана, сеть, STG, геометрия и трубка
не изменились по вычислительному коду. Общий `source_digest`
изменился из-за удаления неиспользуемого расчёта и правки комментариев.

В пяти JSON-пакетах обновлён только `source_digest`.
После сериализации и распаковки все остальные значения проверены
на точное равенство прежним: поля, сигналы, геометрия и диагностика.
FEM для этой миграции не пересчитывался.
Хеши данных и рисунков обновлены; проверка согласованности осталась включённой.
