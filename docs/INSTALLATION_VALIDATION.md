# Проверка парной установки перед публикацией

16 октября 2026 года. Повторно проверена macOS, Julia 1.10.12.

Созданы два новых локальных клона закоммиченных репозиториев в общей
временной папке: `meta-ndt` и `meta-demo`. В них нет незакоммиченных
исходников из рабочих папок. Использован существующий кэш пакетов Julia:
это не проверка установки Julia на пустой компьютер.

Библиотека: `6ae6c289d776c09e0fd5932c4e90083a9dffddd0`.
Эта же ревизия закреплена в CI демонстрации. Ссылка в
`demo/Manifest.toml` относительная: `../../meta-ndt`.

| Проверка из чистой пары | Результат |
|---|---|
| `Pkg.instantiate()` и загрузка MetaNDT | Успешно; путь модуля указывает на соседний клон |
| `test/installation.jl` | 6/6; отсутствие библиотеки обнаруживается до активации окружения |
| `test/canonical_ui.jl` | 166/166; все готовые пакеты читаются и соответствуют источникам |
| `test/canonical_pluto.jl` | 16/16; реальный Pluto, все пять опытов, без открытия браузера |
| `test/canonical_ui.cjs` | Декодирование, датчики, временные кадры и локальные действия проходят |
| `test/canonical_plot_data.cjs` | Несущие входят в диапазоны подготовленных характеристик |
| `test/stg_focus_observation.cjs` | Отмеченное сечение согласуется с измеренной перетяжкой |
| `test/practicum_docs.py` | 5/5; главы, рисунки и готовые документы согласованы |

Перед клонированием также прошли основной набор тестов библиотеки,
проверка жизненного цикла всех карточек и тесты ресурсов общего стенда.
Чистые клоны после проверок не изменились.

В публикацию включены пять подготовленных наборов полей, исходники
методички, PDF и автономный HTML. Временные расчёты, журналы, Python-кэш
и предоставленная книга исключены.

Windows-гайд написан, но чистая Windows-установка локально не проверялась.
CI отдельно проверяет Julia 1.10 и текущую Julia на Windows, macOS и Linux;
его состояние следует смотреть на GitHub, а не выводить из этого отчёта.
