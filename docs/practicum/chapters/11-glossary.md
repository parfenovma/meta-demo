# Обозначения и словарь {#glossary}

## Единицы

| Запись на экране | Значение |
|---|---|
| Hz, Гц; kHz, кГц | Колебания за секунду; 1 кГц = 1000 Гц |
| Pa, Па; GPa, ГПа | Давление: 1 Па = 1 Н/м²; 1 ГПа = $10^9$ Па |
| m, м; mm, мм; nm, нм | Метр; $10^{-3}$ м; $10^{-9}$ м |
| ms, мс; μs, мкс | $10^{-3}$ с; $10^{-6}$ с |
| kg/m², кг/м² | Масса единицы площади |

Записи $5\times10^{-4}$ и `5e-4` означают 0,0005.
Единицу всегда читайте на оси.

## Символы

| Символ | Смысл |
|---|---|
| $p$, $p_i$, $p_s=p-p_i$ | Полное, падающее и рассеянное отклонение давления, Па |
| $\mathbf u$, $u_y$ | Смещение твёрдого тела и его компонента по y, м |
| $\mathbf v$ | Скорость частиц, м/с |
| $f$, $\omega=2\pi f$ | Частота, Гц; угловая частота, рад/с |
| $\lambda=c/f$ | Длина волны в однородной среде |
| $\rho$ | Плотность; в эффективной модели - инерционный отклик |
| $\sigma_\mathrm{eff}$ | Динамическая поверхностная масса, кг/м² |
| $K$, $\beta=1/K$ | Объёмный модуль, Па; сжимаемость, Па⁻¹ |
| $Z$ | Импеданс: давление / нормальная скорость |
| $A$ | Доля поглощённой мощности |
| $Q=\int u_y^2dt$ | Накопленный квадрат смещения, не энергия |
| $D$ | Отличие от эталона в заданной области и окне |
| Re | Действительная часть комплексного отклика |

## Термины

**Контроль** - результат для сравнения; это не обязательно пустая среда.

**Резонанс** - сильный отклик около собственных частот.
**Антирезонанс** - малый суммарный отклик при сокращении вкладов;
части системы могут продолжать двигаться.

**Фаза** - положение в цикле. **Дисперсия** - зависимость
волнового отклика от частоты.

**Эффективная среда** - описание структуры через усреднённые свойства
в проверенном режиме. **Анизотропия** - зависимость отклика от направления.

**Дифракция** - перестройка поля у апертуры, края или препятствия.
**Апертура** - поперечный размер области формирования или приёма волны.

**FWHM** - ширина выбранного пика на половине его собственной высоты.
**Фокусировка** - пространственная концентрация волны.
**Разрешение** - способность различить объекты при заданных измерениях,
шуме и критерии; одна ширина пучка его не определяет.

**Ground cloak** - приближение отражения от выступа к отражению
от ровного основания. **Компенсация рассеяния** - уменьшение рассеянного
поля откликом оболочки. Ни то ни другое не является синонимом поглощения.

**FEM** - метод конечных элементов, приближённое решение на сетке.
**Плоская деформация** - двумерное допущение упругости,
не точное описание любого трёхмерного тела.
