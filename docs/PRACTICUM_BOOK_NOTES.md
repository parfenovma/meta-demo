# Проверка книги для практикума

Источник: предоставленный локальный PDF *Acoustic Metamaterials: Negative
Refraction, Imaging, Lensing and Cloaking*, R. V. Craster, S. Guenneau (eds.),
Springer, 2013, DOI 10.1007/978-94-007-4813-2. Выходные данные проверены
по титульным страницам PDF и странице издателя. Файл не копируется в репозиторий.

## Прочитанные фрагменты и назначение

| Печатная страница | PDF-страница | Использование |
|---|---:|---|
| 1–4 | 16–19 | История отрицательного преломления, ранние резонансные структуры |
| 6–12 | 21–27 | Механические аналоги, эффективные параметры, скалярная/векторная задача |
| 86–87 | 100–101 | Упругие моды стенок, ограничения жёсткой модели |
| 104–106 | 118–120 | Взаимодействие отверстий, периодичности и движения пластины |
| 108–109 | 122–123 | Различие световой и акустической передачи |
| 169–175 | 181–187 | Анизотропная инерция, блокирование потока, carpet cloak |
| 197 | 208 | Постановка обратной задачи; короткая цитата в работе 5 |
| 201–203 | 212–214 | Преобразование полей и тензорной плотности |
| 241–242 | 251–252 | Отличие компенсации рассеяния от трансформационного подхода |
| 247–248 | 257–258 | Выбор эталона, влияние резонанса контрольного объекта |

Нумерацию не получали прибавлением одного общего сдвига: в PDF пропущены
разные пустые страницы. В практикуме ссылки даны по печатной нумерации.
Иллюстрации книги не воспроизводятся. Пересказ не является переводом всей главы.

Исторические формулировки ограничены конкретными датами и устройствами.
Противоречивые широкие утверждения о том, кто именно «ввёл термин
metamaterial», из разных вступительных фрагментов книги не переносились.
