# Начните здесь — программировать не обязательно

Эта инструкция рассчитана на человека, который никогда не открывал Julia и не
обязан знать, что такое «окружение», «пакет» или «локальный сервер».

Нужны:

- обычный компьютер с Windows, macOS или Linux;
- современный браузер;
- интернет только для первой установки;
- около 10 минут и примерно 1 GB свободного места с запасом.

## Шаг 1. Установите Julia

Используйте только официальный сайт:
<https://julialang.org/downloads/>.

### Windows 10 или 11

Самый простой способ — установить **Julia** из Microsoft Store по ссылке с
официальной страницы. Если вы привыкли к Windows Terminal, можно выполнить:

```powershell
winget install --name Julia --id 9NJNWW8PVKMN -e -s msstore
```

После установки **закройте и заново откройте** Terminal.

### macOS

Откройте приложение **Terminal** (Finder → Applications → Utilities →
Terminal) и вставьте одну строку:

```bash
curl -fsSL https://install.julialang.org | sh
```

Согласитесь со стандартной установкой, затем закройте и снова откройте
Terminal.

### Linux

Откройте Terminal и выполните официальную установку:

```bash
curl -fsSL https://install.julialang.org | sh
```

Затем закройте и снова откройте Terminal. Официальный проект Julia рекомендует
`juliaup`, а не старую Julia из системного `apt`/`dnf`.

### Быстрая проверка

Во вновь открытом терминале напишите:

```text
julia --version
```

Если появилась строка `julia version ...`, всё готово.

## Шаг 2. Скачайте демонстрацию

На странице GitHub нажмите зелёную кнопку **Code**, затем **Download ZIP**.
Распакуйте ZIP в обычную папку. Не запускайте файлы прямо внутри архива.

## Шаг 3. Запустите

### Windows

Откройте распакованную папку и дважды щёлкните:

```text
start_windows.bat
```

Если окно сразу закрылось, нажмите правой кнопкой внутри папки → **Open in
Terminal** и выполните:

```powershell
julia --startup-file=no --project=. start.jl
```

### macOS

Самый надёжный способ:

1. откройте Terminal;
2. напишите `cd ` с пробелом;
3. перетащите распакованную папку из Finder прямо в окно Terminal;
4. нажмите Enter;
5. выполните:

```bash
sh start_macos.command
```

### Linux

Откройте распакованную папку в файловом менеджере, выберите **Open in
Terminal** и выполните:

```bash
sh start_linux.sh
```

## Что произойдёт

1. В первый раз Julia скачает несколько пакетов. Это может занять несколько
   минут. Не закрывайте терминал, даже если некоторое время ничего не меняется.
2. В браузере откроется Pluto и сам ноутбук «Виртуальный дефектоскоп».
3. Дождитесь, когда исчезнут индикаторы вычисления.
4. Двигайте ползунок шума, переключайте дефект и меняйте номер измерения.

Адрес будет начинаться с `http://localhost:` или `http://127.0.0.1:`. Это ваш
собственный компьютер: данные никуда не загружаются.

## Как остановить

Закройте вкладку браузера. Затем вернитесь в терминал и нажмите:

```text
Ctrl+C
```

## Если не получилось

### `julia: command not found` или «julia не является командой»

Закройте все терминалы, откройте новый и ещё раз выполните `julia --version`.
Если не помогло — переустановите Julia с официальной страницы и выберите
стандартные настройки.

### Браузер не открылся

Посмотрите на последние строки терминала. Там будет адрес вида
`http://localhost:1234`. Скопируйте его в браузер вручную.

### Windows спросила про доступ через брандмауэр

Для локальной работы публичный доступ не нужен. Не разрешайте доступ через
публичные сети. Pluto по умолчанию открывается только на этом компьютере.

### Первая установка долго стоит на месте

Проверьте интернет и подождите ещё несколько минут. Повторный запуск обычно
быстрый, потому что пакеты уже сохранены.

### Появилась красная ошибка

Не удаляйте файлы наугад. Скопируйте **первую красную строку и 10 строк после
неё** — этого обычно достаточно, чтобы помочь.

## Если вы всё-таки программист

Обычный запуск:

```bash
git clone https://github.com/parfenovma/meta-demo
cd meta-demo
julia --startup-file=no --project=. start.jl
```

Тесты:

```bash
julia --startup-file=no --project=demo -e 'using Pkg; Pkg.instantiate()'
julia --startup-file=no --project=demo test/runtests.jl
```
