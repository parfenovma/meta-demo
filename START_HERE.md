# Запуск стенда

[README](README.md) содержит установку для macOS и Windows,
первый опыт и разбор ошибок.

Скачайте **оба репозитория** и положите рядом:

```text
acoustic-lab/
  meta-demo/
  meta-ndt/
```

Если Julia 1.10 установлена через Juliaup, из папки `meta-demo` выполните:

```sh
julia +1.10 --startup-file=no --project=. start.jl
```

Откроются пять готовых опытов. Выберите карточку и нажмите
«Запустить импульс»; дальше следуйте [методичке](docs/practicum/README.md).
Для остановки вернитесь в терминал и нажмите `Ctrl+C`.
