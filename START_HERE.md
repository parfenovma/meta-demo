# Начните с README

Полная инструкция теперь находится в [README.md](README.md):
установка Julia на macOS и Windows, загрузка двух папок, запуск,
первый опыт, остановка и разбор ошибок.

После запуска откройте [физический практикум](docs/practicum/README.md).
Обычный старт показывает шесть готовых опытов, не редактор с кнопкой
«Рассчитать опыт».

Для запуска обязательно скачайте **meta-demo и meta-ndt вместе**.
Положите их рядом: `acoustic-lab/meta-demo` и `acoustic-lab/meta-ndt`.
Две команды клонирования приведены в README; одной `meta-demo` недостаточно.

Если Julia 1.10 уже установлена через Juliaup и терминал открыт внутри
`meta-demo`, команда запуска:

```sh
julia +1.10 --startup-file=no --project=. start.jl
```

Не закрывайте терминал до окончания работы. Для остановки нажмите `Ctrl+C`.
